三大核心功能

一个扩展，覆盖浏览外文网页的全部场景

🌐

全页面翻译

一键翻译整页可见文本，按钮提示、图片描述、输入框占位符也不放过。原文随时可一键恢复，链接与代码安全不受影响。

✏️

划词翻译

选中任意文字，气泡即刻出现在选区旁，点击翻译即可查看译文并一键复制，不改动页面任何内容。

📝

网页总结

长文不想读？让模型替你读完：自动提炼页面标题、一句话概述与 4–6 条核心要点，显示在页面右侧。

为什么选择墨译

小而美，快而稳

智能方向识别自动模式按内容判断中英方向，一段英文一段中文的混排页面也能正确互译。
模型随你切换填入 Base URL 与 API Key 即可使用 DeepSeek 或任意 OpenAI 兼容接口，不被单一服务绑定。
隐私优先设置与记录全部保存在本地浏览器，不经过任何第三方服务器中转。
批量并发，快而不乱整页文本智能分批、三路并发请求，失败自动拆批重试，长页面也能平稳译完。
界面不扰页面气泡、进度条与总结面板均隔离在 Shadow DOM 中，样式互不污染，按 Esc 即可收起。

快速上手

四步开始，五分钟搞定

安装扩展

Chrome 120 及以上，在扩展管理页开启「开发者模式」，加载已解压的扩展目录即可。

配置接口

点击工具栏墨译图标，填入 API Key 与 Base URL（如 api.deepseek.com），点击「测试连接」。

选择方向

英译中、中译英或自动识别，在弹窗中一键切换，立即生效。

开始使用

点「翻译此页」翻译全文；选中文字划词即译；点「总结此页」速览长文要点。
